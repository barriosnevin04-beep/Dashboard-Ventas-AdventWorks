# Dashboard Interactivo de Ventas - AdventWorks

Proyecto interactivo desarrollado con Streamlit y asistido por Antigravity para el análisis visual de datos de ventas de AdventWorks.

## Tecnologías Utilizadas
* **Base de Datos:** SQL Server (Data Warehouse) alojado en Somee.
* **Lenguaje:** Python 3.12
* **Dashboard & Visualización:** Streamlit, Pandas y Plotly.
* **Control de Versiones:** Git y GitHub.

## Datos de Conexión a la Base de Datos (Somee)
* **Servidor / Host:** `AdventWorks.mssql.somee.com`
* **Base de Datos:** `AdventWorks`
* **Usuario:** `HelenAmpie_SQLLogin_1`
